# お弁当注文システム - プロトタイプ

職場でのお弁当注文を効率化するWebアプリケーションのプロトタイプです。

## 主な機能

### ユーザー機能
- スマートフォン対応のログイン画面
- 本日のメニュー表示・注文
- 注文履歴の確認
- 数量選択機能

### 管理者機能
- 全注文一覧の確認
- 日別集計（メニュー別の注文数）
- 部署別集計（部署ごとの注文数）
- 月次集計（個人別の注文回数・金額）
- メニュー管理（追加・一覧表示）

## 技術スタック

- **フロントエンド**: HTML/CSS/JavaScript
- **バックエンド**: Node.js + Express
- **データベース**: SQLite
- **スタイル**: レスポンシブデザイン（モバイル対応）

## セットアップ方法

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. サーバーの起動

```bash
npm start
```

サーバーが起動すると、`http://localhost:3000` でアクセスできます。

### 3. ブラウザでアクセス

ブラウザで `http://localhost:3000` を開いてください。

## 使い方

### ユーザーとして注文する

1. 一般ユーザーアカウントでログイン
2. 「注文する」タブで本日のメニューを確認
3. 数量を選択して「注文する」ボタンをクリック
4. 「注文履歴」タブで過去の注文を確認

### 管理者として集計する

1. 管理者アカウントでログイン
2. 「注文一覧」タブで全注文を確認
3. 「集計」タブで以下の集計が可能：
   - **日別集計**: 特定日のメニュー別注文数
   - **部署別集計**: 特定日の部署別注文数
   - **月次集計**: 特定月の個人別注文回数と金額
4. 「メニュー管理」タブでメニューの追加・確認

## データベース構造

### users（ユーザー）
- id: ユーザーID
- name: 氏名
- email: メールアドレス
- password: パスワード
- department: 部署
- role: 権限（user/admin）

### menus（メニュー）
- id: メニューID
- name: メニュー名
- description: 説明
- price: 価格
- available_date: 提供日

### orders（注文）
- id: 注文ID
- user_id: ユーザーID
- menu_id: メニューID
- order_date: 注文日
- quantity: 個数
- status: ステータス

### departments（部署）
- id: 部署ID
- name: 部署名

## トラブルシューティング

### ポート3000が既に使用されている場合

`server/index.js` の `PORT` 変数を別のポート番号に変更してください。

```javascript
const PORT = 3001; // 例: 3001に変更
```

### データベースをリセットしたい場合

`bentou.db` ファイルを削除して、サーバーを再起動してください。

```bash
rm bentou.db
npm start
```
